# 语录分类抽取、文字配色与个人更新渠道

状态：用户已确认全部方案，Windows 个人版 1.4.3 按以下规则实现。

## 改造前的行为

- 开启生成后，合并常驻和生成语录，按规范化文本去重；只要还有未展示语录，就排除所有已展示语录。preferred 只在剩余候选中乘三，其他单句权重也继续生效。
- 关闭生成后只抽常驻语录，不使用未展示优先；preferred 仍乘三。有其他候选时避开紧接上一句。
- 展示历史依据实际可见的气泡记录，与生成开关无关。生成完成和候选被抽中本身不代表已经展示。
- 目前先抽台词，再独立抽变色效果。默认全体变色 0.5%、仅文字变色 3%，其余原色。现有颜色使用共享流动相位，配色设置入口在普通菜单中隐藏。
- 可复用挂件现有粉、紫、蓝、绿、金等调色板；现有深浅混色有利于区分文字和底色，但没有计算或保证对比度阈值。

## 已确认的决策

1. 三个互斥类别：preferred、非 preferred 的已展示语录、非 preferred 的未展示语录。取代当前未展示优先、preferred 三倍和单句权重。
2. 按抽取时类别配色：preferred 使用挂件紫色 #745A98；非 preferred 已展示语录使用黑色；非 preferred 未展示语录首次出现使用流动彩虹文字。本次展示期间颜色不变，记录展示历史后不立即切黑，下次抽取才重新分类。
3. 类别为空时，在其余有库存且占比大于零的类别之间按原比例重新分配。
4. 占比优先。先按类别占比抽取，再在该类内部随机轮换；不为避免连续同句而跳到另一个类别。该类只有上一句时允许连续重复。
5. 默认 preferred 40%、非 preferred 已展示 20%、非 preferred 未展示 40%。用户可修改，三项合计必须为 100%；0% 表示不抽该类。所有非零类别均无库存时提示调整，不擅自启用零占比类别。
6. 生成开关仅控制是否允许继续创作，不影响已有生成台词的展示。独立的“生成语录参与展示”设置默认开启，用户可修改。
7. 调整展示占比本身不发起模型调用，也不修改自动补货限制。

## 轮换与发布的确认

- 保存组内轮换进度，重启后继续；新增、删除、改分类时保留其他语录的轮换进度。
- 当前 Windows 安装迁移到现有个人 fork 的发布渠道，日常更新仅跟随个人 Release，上游代码自行选择合入。

## 实现与兼容

- 三类占比、已有生成语录参与展示和分类配色开关保存在独立的 quote-selection.json。配色开关兼容原 coloredText 字段。调整这些选项不会写入生成设置或启动模型。
- 轮换保存各类成员和未轮到的语录哈希，随实际展示历史一并原子保存到 quote-history.json。抽中但未实际展示的候选不推进磁盘进度。旧版历史可直接读取，历史中的首次展示时间保留。
- 新成员加入该类的待展示队列；删除或移出类别的成员从该类队列剔除。旧单句权重保留以便兼容，但不影响新分类抽取。
- 分类文字色优先于原有文字效果；气泡和角色原有效果可继续运行。未展示文字使用独立的彩虹渐变画刷，与原有效果共享平移相位，2.6 秒循环；不受台词关键词配色影响。隐藏或收起时停止仅供文字的动画。关闭分类配色选项恢复原配色行为。

## 个人仓库与更新渠道的事实

- 已有个人 fork：Difigo/GPT-Niang，Git origin 指向该仓库；upstream 保留 T7moris/GPT-Niang。
- Windows 个人版更新器的 Release API 和下载路径固定到 Difigo/GPT-Niang；上游下载地址不再被允许。保留下载来源限制、SHA256、ZIP 和安装清单校验。
- 个人版使用独立递增的三段数字版本，从 1.4.0 开始，不用带后缀的版本号。
- windows-personal.yml 在个人仓库的 main 推送或手动触发时测试、构建；仅 main 在 Windows 检查通过后发布。已发布版本不覆盖，修改代码后发布需递增版本号。上游双平台工作流仅在上游仓库运行。
- 当前安装迁移渠道可保留用户数据；与原版并装还需隔离共享数据目录、启动器和安装身份，不是本轮默认方案。
- 个人包继续保留项目许可与素材来源声明。

## 提案的作用与边界

先按类别占比选类别，再从该类别中选句，可以让 preferred 的类别份额不受普通库存增长影响。举例：preferred 占比 40%、有 10 条，则每条的长期份额约为全部展示的 4%；普通语录从 100 条增加到 1000 条，也不会因此稀释这部分份额。实际短期结果受随机波动、轮换和有效类别变化影响。

preferred 本身越来越多时，每条仍会分到更少的份额。类别占比是长期目标，不是每几次点击必定出现固定次数的承诺。
